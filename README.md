# WA Bridge

Small Android app for AMClub hiring. It reads WhatsApp notifications from unsaved numbers
(and known candidates), forwards them to a private cloud inbox, and shows reply drafts for
approval. Approved replies are sent through the notification's Reply action, or by opening
WhatsApp with the text typed in.

No secrets live in this repo. The app needs a setup code entered on the phone.

Builds: every push to `main` builds a debug APK and attaches it to a GitHub Release.
